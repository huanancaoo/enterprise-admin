## 已确认的数据库身份边界

[S8 集成约束](s8-integration-contract.md) 记录了 2026-09-28 的用户决定：API 统一使用 `DATABASE_URL` / `app_runtime`，替换原来平台独立 `platform_runtime` Pool 的要求。T22/T23 必须按这个事实验收，不能继续把旧规格中的“app_runtime 不可调用任何平台函数”宣称为当前结果。

当前 app_runtime 可以调用已交付的参数化固定平台函数，但不能直接读写任职、收据或平台投影视图，也不能继承 executor/部署身份。函数重查任职、Session/MFA 和动作；actor/Session 参数来自服务端认证。该设计不证明取得任意 app_runtime SQL 执行能力的攻击者仍受最终用户边界约束；数据库不会仅凭 actor 参数证明最终用户身份。租户 RLS、组织上下文清理、私有表权限和 HTTP 最终用户授权分别有各自证据。
