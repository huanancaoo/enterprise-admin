# S9-03–07：核心 Worker 实施与验收

对应 [#30](https://github.com/huanancaoo/enterprise-admin/issues/30)。用户已确认正式生产者 → 真实 Redis/BullMQ → 独立 Worker → 当前授权与 TenantTx → 持久业务结果及审计的测试边界，并在实施时明确 Worker 不是可选项。

## 实现范围

- `@workspace/jobs` 提供严格 JSON 任务契约、规范化业务意图、稳定队列身份、生产者确认、永久错误与有界重试，以及独立消费者和结构化日志。
- `@workspace/database/task-tenant` 在同一组织锁与事务中核对当前成员和角色，重建 TenantContext，复用 HTTP 与后台共享的 TenantTx 初始化。不存在组织、移除成员、撤权或停用均永久拒绝。
- Worker 是默认核心运行时，根开发入口、Compose 和每次发布都包含它；生产镜像独立构建、使用 app_runtime 和非 root 用户。发布顺序固定为 migrator → API → Worker → SPA → smoke。
- 未新增生产业务任务、通用任务 HTTP/UI、任务目录或事务投递 outbox。邮件和 Files 的既有执行与系统清理语义保持各自职责。

## 已执行的批次验证

| 范围            | 实际结果与边界                                                                                       |
| --------------- | ---------------------------------------------------------------------------------------------------- |
| 当前成员授权    | 最终 4 文件、110/110 真实数据库回归通过，包含 10 项新增授权边界验证                                  |
| Worker 完整集成 | 最终完整 Worker 集合 20/20 通过，包含真实 Redis/PostgreSQL、独立进程与提交前死亡后正式撤权的组合用例 |
| 类型与规范      | 全仓 lint、typecheck 各 19 个任务通过；依赖边界通过                                                  |
| 单元入口        | 工程/契约集合 106 项、API 单元 45 项、文档 25 项通过，包含 jobs 公开契约测试                         |
| 文档            | 文档内容检查 38 页、任务文件格式及 3 处 Worker 文档本地链接通过                                      |

主要进程证据包括提交前 SIGKILL 的事务回滚、提交后确认前 SIGKILL 的幂等重放、提交后撤权的队列拒绝与原成功事实保留、SIGTERM 正常排空、关闭期限耗尽的非零退出及重启恢复。传输测试只暂缓真实 Redis 对特定 Job ID 的成功响应；请求实际写入 Redis，再核对未知结果与同意图重试。

测试 Redis 使用固定的随机宿主端口，正常重启保留同一端点与持久数据。首轮随机端口随容器重启变化造成的连接错误是夹具问题；生产者断线期间返回 unknown，恢复后的确认与重试继续使用同一任务身份。

实际发现并修正：不存在的组织原先透传 ORS01，被当作暂时执行故障重试。真实消费者失败用例复现后，数据库入口将其映射为与成员不存在相同的永久 MEMBERSHIP_REQUIRED，不暴露组织存在性；其他数据库/连接故障仍保留暂时错误分类。

既有回归：Nest HTTP 15/15、真实业务 API 33 文件 495/495 通过。生产镜像与核心发布门禁 3/3 通过，包括非 root 就绪及退出、运行角色拒绝、真实 SQL 迁移失败阻止发布、必需 Worker 就绪阻止后续 SPA，以及 Redis 持久化设置。

镜像初次冷构建因依赖下载超过原测试时限而中止；随后将 Worker 构建与前端分离，共用依赖缓存并为镜像构建设置独立测试时限，实际重跑通过。Worker 就绪和关闭期限的产品门槛未放宽。

上述批次事实不代替远端 CI、外部部署或具体生产任务的业务验收。S8 历史发布用例只回退 API/SPA 并保留本轮 Worker 镜像，不声明完成 Worker 版本回退；该历史回退任务仍与 #30 的核心运行时验收分开。
