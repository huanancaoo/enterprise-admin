# S8-15 平台设置验收

对应 [Issue #23](https://github.com/huanancaoo/enterprise-admin/issues/23)，验证日期为 2026-10-02。本记录覆盖平台默认语言、部署摘要及其实际消费者。S8 全量组合、发布升级与规定规模性能验收仍属于 #24。

## 设置、身份与审计

`GET/PATCH /api/v1/platform/settings` 使用统一 app_runtime 连接池调用参数化固定函数。唯一可写字段是 platformDefaultLocale；支持 zh-CN、en-US、ar。读取投影包含设置版本、支持语言、运行环境、API 应用版本和 SMTP 配置布尔值，不包含地址、口令、连接串、secret 或私钥。配置布尔值只描述配置完整性，不表示 SMTP 在线或投递成功。

0036 建立必有的单例设置及 RLS。app_runtime 只可直接读单例键和默认语言，不能读取版本、修改设置或 SET ROLE 到 executor。NOLOGIN platform_executor 持有固定函数，限定列权限、search_path、row_security 和事件范围；PUBLIC、历史运行角色、部署账号没有函数调用权。既有租户 Projects 与审计隔离不放宽。

有效管理员与审计员都可读，读取先写一次私有 platform.settings_viewed 审计。仅管理员可修改，要求权威 Session 的 15 分钟内 MFA、10–500 字符操作原因、expectedVersion 和 Idempotency-Key。锁等待后再次查权，再处理 24 小时幂等收据。变更、版本、私有 platform.settings_updated 审计和收据原子提交；同键同体重试不重复写事实，同键不同体、陈旧版本拒绝。no_change 有尝试审计但不增加版本。审计写入失败不返回成功。

## 语言消费者与页面

业务 HTTP 按支持的请求头、个人、组织、平台顺序协商响应语言；本人偏好和组织访问 effectiveLocale 排除请求头。原生认证错误读取持久化平台默认语言。Projects 在 TenantTx 内解析组织默认或平台默认基础语言。邮件按收件人个人、相关组织、平台默认解析，发送人的 UI 请求头不覆盖收件人语言。修改不改写已有个人、组织偏好，也不重写已渲染邮件；客户端保留当前 UI 语言，遵循已确认的语言行为。

Settings 页面按用户隔离查询缓存，管理员使用 TanStack Form、Zod 与 Field；审计员只读。提交期间禁用表单并保留草稿，错误不清空输入。结果未知时，同一输入继续使用同一幂等键；修改输入产生新操作。版本冲突提供明确的放弃草稿并重载操作，成功更新设置事实并失效本人继承查询。401/403 清理平台缓存并按现有身份/MFA/访问拒绝路径跳转。
