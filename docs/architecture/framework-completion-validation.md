## 本轮新增验收

- 原生改密 HTTP：客户端传 `true`、`false` 或省略选项，服务器都撤销其他 Session，同时原生 Cookie 更新后保留当前登录；邮箱验证与用户 ID 保持、独立会话撤销一并 5/5 通过。
- 与生产共享的启动入口：真实 HTTP 导入、Redis 和独立 Worker 终态，自动发送至本地 Mailpit 与 Webhook 接收端；实际收件人、任务链接、原始字节 HMAC、站内通知与发送状态均通过，载荷不含项目私密值。
- 原始 10,000,000 字节 CSV 经正式 JSON、Redis、Worker 完整导入；超出一个字节的 CSV/XLSX 在创建持久任务前拒绝；多个 XLSX 工作表整批失败、报告 `INVALID_WORKSHEET_COUNT`、零新增。
- 同组 35 条 HTTP 用例初次 34/35；普通超大请求被 body-parser 错误报告为 500，已在 HTTP 错误边界修正为 413，完整回归通过。
- 最终完整 HTTP 回归：Nest 15/15、47 个文件的真实业务 562/562 通过，已包含行号、正文事件、大小限制、自动投递和空闲数据库断连用例。
- 数据库主动断开空闲连接：真实独立 API 不退出，仅记录受控 `database.pool.failed` 诊断，后续正式 HTTP 仍可用；SQL 参数及畸形 JSON 日志边界一并 3/3 通过。
- 两轴审查：4 类表单规范差异与 2 项规格发现均已修正并独立只读复核关闭；CSV 起始文本行、正文薄事件及事务回滚有实际 HTTP 证据。
