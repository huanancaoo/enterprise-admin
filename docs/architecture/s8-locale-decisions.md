# S8 语言行为确认

2026-09-28 用户确认：客户端始终发送当前 UI 语言的 `Accept-Language`；切换组织时优先保持原显示语言。

- HTTP 内容协商仍按受支持的请求头、个人偏好、组织默认语言、平台默认语言解析，并返回对应 `Content-Language`。
- 组织切换刷新访问上下文与组织数据，保持当前 UI 语言。组织继承语言可以与当前显示语言不同。
- 本人偏好和组织访问响应中的 `effectiveLocale` 表示持久化偏好继承结果，排除当前请求头；响应头的内容协商仍包含请求头。
- 保存个人语言选择立即更新当前 UI；清空个人偏好时，在当前组织上下文中使用组织继承语言，无组织时使用平台默认语言。
- 新账号上下文从服务端继承结果初始化语言，个人偏好查询按 userId 隔离。平台完成 MFA 后的整页加载同样初始化个人语言，不能沿用其他账号的显示状态。

此确认覆盖父 #8 和子 #17 中“切换组织后重新计算显示语言”的旧表述。邮件支持语言范围需单独确认，本文不扩大邮件模板范围。
