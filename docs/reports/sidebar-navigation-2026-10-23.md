# tenant 与 platform 导航重组

2026-10-23。按确认的新版 tenant 与 platform 分区实施，并根据后续决定完整删除动态菜单管理，platform 导航改为固定代码配置。

## 导航结构

Tenant 使用三个常驻分区，标题不可点击、不折叠：

- 业务工作：项目、文件、任务中心。
- 组织管理：成员与邀请、角色权限、操作日志、常规设置。
- 开发集成：API Key 与 Webhook。

任务中心从页头迁入侧栏；页头保留公告阅读和通知。组织管理原横向导航取消。原 URL、组织切换和新建组织落点保持；常规设置仅在原有 `canRead` 条件满足时展示，不影响其他分区入口。

Platform 保留七个一级入口和 17 个业务页面：

| 一级入口 | 页面                                   |
| -------- | -------------------------------------- |
| 组织管理 | 一级直达                               |
| 全局账号 | 一级直达                               |
| 内容管理 | 公告管理、文件                         |
| 平台团队 | 员工管理、部门管理、岗位管理、角色管理 |
| 安全审计 | 在线用户、登录日志、操作日志           |
| 运行管理 | 导入导出任务、定时任务、运行监控       |
| 系统配置 | 字典管理、参数设置、平台设置           |

`platform-pages.ts` 登记路由、查询、权限和固定导航关系。导航使用当前访问权限过滤页面，剔除空目录；首页在路由加载阶段进入首个获准页面。详情深链匹配真实路径分段。目录仅展开，收起为图标时点击目录会展开完整侧栏，移动端点页面后关闭抽屉。

业务模块生成器同步使用新导航结构：新建业务页面进入“业务工作”，其分区面包屑、组织切换和创建组织落点共用页面登记。

## 删除动态菜单管理

移除菜单管理页、菜单 CRUD/registry/navigation HTTP 接口、动态外链及 iframe 路由、菜单导出入口与工作簿列、相关契约和生成客户端。角色授权页从现有 `@workspace/permissions` 目录读取可授予动作，服务端仍校验授权写入。

迁移 `0109_remove-dynamic-menu-functions` 替换仍在使用的系统目录、角色授权与任务函数，删除菜单专用协议和函数，并从所有角色清理 `platform.menu:*`。内置角色保护触发器仅在迁移事务持锁清理期间暂停，随后恢复。

迁移 `0110_remove-dynamic-menu-storage` 删除 `platform_menu` 和 `platform_iframe_origin_allowlist`。其数据及管理员自定义动态导航随功能一起删除。历史任务流水保留提交时的资源标识；可创建和执行的导出资源不再包含菜单。历史 migration 保持不变。
