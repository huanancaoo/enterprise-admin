# 交互载体

为每个 Create、Edit、Show 或其他界面任务独立选择载体。先应用排除条件，再比较适用条件；载体之间不存在按字段数量递增的等级关系。

## 独立页

出现任一条件时选择独立页：

- 任务需要稳定 URL、浏览历史、刷新恢复或链接分享。
- 用户需要长时间专注，或需要跨区域查阅信息。
- 信息由多个有独立含义的分组、阶段或视图组成。
- 任务是当前主要工作，来源页面不再提供持续价值。

独立页不是全屏弹层。为减少路由开发而把主要任务压入 Dialog 或 Sheet，会破坏定位、恢复和导航语义。

## Sheet

来源页面在任务过程中必须持续提供有价值的上下文时选择 Sheet，例如从列表查看关联详情，或参照当前集合完成局部编辑。

以下情况排除 Sheet：

- 来源上下文对完成任务没有实际作用。
- 任务需要稳定 URL、刷新恢复或长时间专注。
- 内容宽度或信息结构要求已经使任务成为主要工作。

Sheet 是上下文保留工作区，不是大号 Dialog。

## Dialog

同时满足以下条件时选择 Dialog：

- 任务需要暂时中断当前界面。
- 任务边界明确，能够在一次短操作中完成或取消。
- 完成任务不需要离开当前上下文查阅信息。
- 不需要稳定 URL、刷新恢复或持续编辑。

确认操作可以具有较高风险；风险高低不单独决定 Dialog。复杂录入、多阶段流程和跨页面参照不属于封闭短任务。

## 无法决定时

不要选择“最接近”的载体。指出尚未确认的是任务主要性、来源上下文价值、定位恢复需求还是信息结构，并作为产品决策询问用户。
