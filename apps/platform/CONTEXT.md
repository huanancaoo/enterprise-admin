# 平台后台

平台管理员的产品操作面。范围是跨组织或针对平台自身，不是自助开通组织的入口。

## Language

**平台后台**：
平台管理员的产品操作面。
_Avoid_: 超管后台, 运营后台, Platform Admin

**后台领域组件**：
租户后台与平台后台共用的后台组合层，不是平台后台本身。
_Avoid_: 租户后台的包, admin 应用

**平台页面**：
可从平台菜单进入的内部操作界面。页面登记限定可选目标，任职权限决定员工能否访问。
_Avoid_: 菜单权限, 前端授权

**平台菜单**：
平台员工可见的导航安排，包含目录、页面、操作节点、外链和嵌入页。隐藏菜单不撤销访问权限。
_Avoid_: 权限树, 页面清单
