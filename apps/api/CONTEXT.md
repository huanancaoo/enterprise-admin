# 身份与组织

用户、组织、组织成员与平台管理员的归属。租户后台和平台后台都通过这里的 API Host 使用这些概念。

## Language

**用户**：
可登录的身份。用户本身不是组织成员，也不是平台管理员。
_Avoid_: 账号, 客户, 操作者

**组织**：
成员所属的隔离单元。「租户」只作租户后台的前缀，不是这个实体的名字。
_Avoid_: 租户, 公司, 团队

**组织成员**：
属于某个组织、在租户后台做事的人。由该组织的成员关系产生。
_Avoid_: 租户操作者, 租户用户, 租户

**组织角色**：
组织成员在该组织内的权限身份。内置为 owner、admin、member；一个组织还可以有自定义角色。组织角色不能产生平台任职。
_Avoid_: 平台角色, editor, viewer, 租户角色

**邀请**：
对指定邮箱发出的、带一个组织角色的待加入请求。它还不是组织成员关系。
_Avoid_: 邀请码, 成员申请, 分享链接（当邀请本身）

**平台管理员**：
在平台后台做事的人。由平台任职产生。组织角色、打开平台后台的路由都不能产生。
_Avoid_: 超管, 运营, 平台操作者, 平台用户, 平台账号

**平台任职**：
让一个用户成为平台管理员的独立事实。同一用户可以同时是组织成员和平台管理员，互不推导。
_Avoid_: 超管账号, 平台角色（当组织角色用）

**API Host**：
租户后台与平台后台共用的唯一 HTTP 运行时。授权按成员关系或平台任职执行，不按请求来自哪个后台执行。
_Avoid_: 租户 API, 平台 API

**Worker**：
按需启用的异步运行时。未启用时没有产品职责。
_Avoid_: 第三个后台
