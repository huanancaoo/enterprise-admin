# 身份与组织

用户、组织与两种操作者的归属。租户后台和平台后台都通过这里的 API Host 使用这些概念。

## Language

**用户**：
可登录的身份。用户不是操作者本身。
_Avoid_: 账号, 客户

**组织**：
成员所属的隔离单元。「租户」只作租户后台、租户操作者的前缀，不是这个实体的名字。
_Avoid_: 租户, 公司, 团队

**租户操作者**：
在租户后台做事的人。
_Avoid_: 租户用户, 管理员, Admin

**平台操作者**：
在平台后台做事的人。打开平台后台的路由不等于成为平台操作者。
_Avoid_: 超管, 运营, Platform Admin

**API Host**：
两个操作面共享的唯一 HTTP 运行时。授权按操作者与目标组织执行，不按请求来自哪个操作面执行。
_Avoid_: 租户 API, 平台 API

**Worker**：
按需启用的异步运行时。未启用时没有产品职责。
_Avoid_: 第三个操作面
