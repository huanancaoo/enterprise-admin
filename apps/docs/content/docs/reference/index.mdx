Reference has two layers:

- **HTTP API**: rendered from `apps/api/openapi/openapi.json` by fumadocs-openapi. It covers endpoints, request, response, schema, and errors. It does not include source links or a Try It console.
- **TypeScript SDK**: the generated client in `packages/api-client`. See the [SDK guide](./sdk.mdx).

Pipeline:

```text
NestJS → OpenAPI generate → CI artifact → docs build → API reference
OpenAPI → Orval → api-client → SDK docs
```

The OpenAPI snapshot is the artifact the docs build reads. Do not point the docs site at a running `/api/docs-json`.
