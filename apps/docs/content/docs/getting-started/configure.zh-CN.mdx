按[仓库快速开始](https://github.com/huanancaoo/enterprise-admin/blob/main/README.md#快速开始)分别配置 API 和 Worker，再启动整个工作区。Worker 必须有自己的 `apps/worker/.env`，其数据库与 Redis 指向同一套运行环境。

环境示例放在实际加载它的进程旁边，根目录 `.env.example` 仅为索引。前端 `VITE_` 与文档站 `NEXT_PUBLIC_` 变量会公开；认证、SMTP、搜索写入等密钥只留在服务端。运行、迁移与初始化凭据分别管理。
