安装与迁移步骤统一维护在[仓库快速开始](https://github.com/huanancaoo/enterprise-admin/blob/main/README.md#快速开始)：安装锁定版本的依赖，先启动 PostgreSQL、Redis 与 Mailpit，再以迁移身份执行数据库迁移。

API 与 Worker 使用运行身份，不加载迁移凭据，也不在启动时执行迁移。完成后按[进程配置](./configure.mdx)配置各应用。
