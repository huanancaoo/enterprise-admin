Follow the [repository quick start](https://github.com/huanancaoo/enterprise-admin/blob/main/README.md#快速开始) to install the pinned dependencies, start PostgreSQL, Redis, and Mailpit, and apply migrations using the migration identity.

The API and Worker use the runtime identity. They neither load migration credentials nor run migrations at startup. Continue with [process configuration](./configure.mdx).
