Configure the API and Worker separately using the [repository quick start](https://github.com/huanancaoo/enterprise-admin/blob/main/README.md#快速开始) before starting the whole workspace. The Worker requires its own `apps/worker/.env`, pointing to the same runtime database and Redis.

Environment examples live next to the process that loads them; the root `.env.example` is only an index. Frontend `VITE_` and documentation `NEXT_PUBLIC_` variables are public. Authentication, SMTP, and search write credentials stay server-side. Keep runtime, migration, and bootstrap credentials separate.
