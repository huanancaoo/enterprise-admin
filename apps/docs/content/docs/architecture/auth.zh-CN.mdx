认证是单一 API Host 上的 Better Auth Organization。

## 租户用户

- 邮箱密码登录
- 邮箱验证与密码重置
- 租户后台的 GitHub 社交登录
- 组织创建/选择、成员邀请与组织角色

认证邮件先写入 durable outbox，再经 SMTP 投递。本地开发使用 Mailpit。

## 平台管理员

平台后台没有注册入口。部署操作者可通过 `platform admin create` 直接创建邮箱已验证的 `platform_admin`；账号、原生密码凭据、独立任职与审计在同一事务提交，不发送验证邮件或创建会话。已有用户仍通过正常认证注册和验证邮箱，再由 `platform assignment grant` 按精确 UUID 授予平台任职。MFA 由账号自主启用，未启用者密码登录后即可进入平台；主动启用后仍须完成原生两步验证登录流程。

平台任职使用独立部署连接 `PLATFORM_ASSIGNMENT_DATABASE_URL` 管理。在线 API 每次平台请求重新检查有效任职与当前会话；撤销任职后，旧会话的下一次平台请求会被拒绝。

组织 owner 不是平台管理员。见 [ADR 0002](../adr/0002-platform-assignment.mdx)。
