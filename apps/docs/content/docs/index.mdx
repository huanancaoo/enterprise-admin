Tenaro is a self-hosted multi-tenant application foundation. It is not an admin UI template and not a marketing SaaS boilerplate. It is a TypeScript skeleton for teams that need a tenant console, a platform console, one API host, PostgreSQL isolation, and a repeatable business-module pattern.

## What you get

- Tenant console for organization members and platform console for platform admins
- One API host: business APIs under `/api/v1`, auth under `/api/auth`
- Better Auth organizations: email/password, email verification, invites, roles
- Database-layer tenant isolation with `TenantTx` and PostgreSQL RLS
- Contract-first HTTP: `packages/contracts` → OpenAPI → Orval client
- Docs-as-Code on this site: Markdown/MDX in Git is the only documentation source

## Who this documentation is for

- People adopting the open-source project
- Teams building on top of it
- Contributors
- Operators who self-host it

This site is developer documentation. It is not the product website, a CMS, an enterprise wiki, or an AI agent platform.
